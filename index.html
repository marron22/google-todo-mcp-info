Google ToDo MCP

Google ToDo MCP は、作者本人が自分の PC で使うための個人用ツールです。AI アシスタントから自分の Google Tasks（ToDo リスト）を読み、タスクを追加できるようにします。

一般向けに配布・提供しているサービスではありません。

プライバシーポリシー

Google ToDo MCP is a personal tool used only by its author on the author's own computer. It lets an AI assistant read the author's Google Tasks and add tasks. It is not offered to the public.
